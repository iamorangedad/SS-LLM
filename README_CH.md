# 秘密分享上的两层网络

[English](README.md)

这是一个最小 demo。两个互不串通的参与方，在加法秘密分享上完成一次两层网络前向。单独一份份额还原不出输入、权重或输出。英文文档是主版本。

```text
h = (W1 @ x + b1) ** 2
y = W2 @ h + b2
```

平方是这个实现里的非线性。它只需要乘法。ReLU 需要比较协议，没有放进这个最小版本。算术在素数域 `2^61-1` 上进行。demo 里的整数很小，所以域上的结果与普通整数前向一致。

## 运行

```bash
pip install -r requirements.txt
python demo.py
python test_ssnn.py
```

`demo.py` 先跑一个可以手算的例子，明文结果是 `[6]`，打印该例子的模拟传输记录，再用一个随机小网络对照。终端输出是英文。

## 协议

- 客户端在本地把输入、两层权重和偏置拆成两份，每个参与方拿一份。
- 加法在本地完成：双方把自己的份额相加。
- 乘法使用 Beaver 三元组。每一方只把 `e` 和 `f` 的掩码份额发到对方地址，再用自己的份额加上收到的份额，还原打开后的掩码。输入、权重和偏置不会被发送。
- 矩阵乘向量由逐元素乘法和本地求和组成。
- 输出份额交回客户端，只有客户端把两份相加。

初始化方负责产生均匀份额和三元组，之后不参与推理。`ssnn.py` 里的 `Dealer` 模拟这个角色。

安全模型是半诚实的：双方按协议计算，并且不会把份额凑到一起。张量形状是公开的。打开的 Beaver 掩码也是公开的；掩码均匀时，它们不泄漏秘密。某一方如果篡改消息，这个 demo 检测不出来。它不加密流量，也不声称能抵御恶意参与方。

## 模拟信道

`comm.py` 模拟两个 IP 地址 `10.0.0.1` 和 `10.0.0.2` 之间的一条链路。`send(src, dst, payload)` 把一段字节复制到目的地址，并记下一条日志：源 IP、目的 IP、字节长度，以及一个短标签（Beaver 掩码份额用 `e` 或 `f`）。一方只能收取发给自己 IP 的消息。

这条链路在进程内完成。它不会打开套接字、不会绑定端口，也不是真实网络。

## 代码

- `comm.py`：`10.0.0.1` 与 `10.0.0.2` 之间的模拟链路
- `ssnn.py`：域运算、拆分、Beaver 乘法、两层前向
- `demo.py`：手算例子、该例子的传输记录，以及随机对照
- `test_ssnn.py`：份额隐私、乘法、手算例子、20 组随机网络、投递、字节长度和信道日志

## 手算例子

```text
x  = [1, 2]
W1 = [[1, 0], [1, -1]]
b1 = [0, 1]
W2 = [[2, 3]]
b2 = [4]

z = [1*1 + 0*2, 1*1 + (-1)*2 + 1] = [1, 0]
h = [1, 0]
y = [2*1 + 3*0 + 4] = [6]
```

秘密分享前向合并后同样得到 `[6]`。
